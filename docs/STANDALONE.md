# 独立使用（浏览器页面）

[返回项目首页](../README.md) · [部署与局域网访问](DEPLOYMENT.md)

不装 DeepSeek Harness 也可以用：本项目自带一套浏览器页面，在本机起一个 Python 看板，
功能和 Harness 面板一致，还多了局域网只读访问和分享链接。两种用法读的是同一份配置和
同一份采集数据，可以并存 —— Harness 面板本身就是去读这个看板的。

想在 Harness 侧边栏里用，见[项目首页](../README.md)。

## 快速部署

准备 **Python 3.11+、Git**，下载本项目，并 clone 需要监控的插件仓库：
[vLLM-Plugin-FL](https://github.com/flagos-ai/vllm-plugin-FL)、
[SGLang-Plugin-FL](https://github.com/flagos-ai/sglang-plugin-FL)。插件 checkout 需包含
所选 remote 的目标分支；首次 clone 后通常已有，缺少时先执行 `git fetch <remote>`。

看板使用 Python 标准库，**无需 pip 安装依赖或 GPU 环境**。建议安装并登录 `gh` 读取
GitHub 状态；执行适配任务时再准备 agent CLI、SSH 和远端 GPU 环境。

在本项目目录运行（Windows / Linux / macOS；系统只有 `python3` 时替换命令中的 `python`）：

```sh
python -B dashboard.py configure
python -B dashboard.py start
```

向导选择一个或两个项目，填写插件 checkout 路径、remote、目标分支和端口；自动生成配置后，
启动器会检查配置及端口。打开 [本机看板](http://127.0.0.1:8766/)，保留启动终端；按 `Ctrl+C`
停止。端口冲突可用 `python -B dashboard.py start --port 9000`。

配置保存在 Git 忽略的 `runs/configured/`，各项目的会话与验收目录独立。向导不会覆盖已有
配置；需要另一套配置时指定 `--output-dir`。已有 `projects.json` 的部署可继续使用原启动
命令。迁移到另一台机器后重新运行向导，验收存档另行导入。

局域网部署沿用这份项目配置，单独启动免登录只读 HTTPS 服务。证书、防火墙、非交互配置及
Windows 登录后常驻的可复制步骤见 [部署指南](DEPLOYMENT.md)。

## 页面入口

| 页面 | 用途 |
| --- | --- |
| `/` | 双仓库适配总览 |
| `/monitor?project=vllm` | 分支、PR、CI 和逐项验收详情 |
| `/sessions?project=vllm` | 验证机器、agent 配置与适配任务 |
| `/devices?project=vllm` | 设备资源、每卡状态与可用性（局域网免登录查看、手动刷新） |
| `/access-shares` | 本机创建、查看和撤销完整权限分享链接（需启用） |

查看 SGLang 时将 `project=vllm` 改为 `project=sglang`。

总览页点击 **“导出 HTML”**，将两个项目当前所选分支的 PR、CI 和验收明细保存为单个文件，
可直接发送、离线打开；本机与局域网访客均可导出。报告保留真实采集时间，缓存或采集未完成
会明确标注。

版本标签随所选分支变化，读取该分支提交的 `pyproject.toml` 中对应引擎的精确依赖版本；
尚未更新依赖声明的升级目标不会自动推断。

## 任务与验收

任务工作台提供「活跃 / 全部 / 回收站」视图，可搜索名称、分支或设备，按状态和 Agent 筛选。
已结束的任务在「全部」中查看；删除任务会移入回收站，可恢复，工作目录和验收记录仍保留。
运行中的任务须先中断。

代码合入、CI 和验收结果分别展示。验收结果汇总 PR 作者在描述中报告的测试结论：通过、
部分通过、未通过或待验收，点击在当前页面展开验收表格，可继续查看原 PR。PR 暂无可识别
结果时，使用关联同一 PR 的本地记录或逐项结果；原始场景和测试版本保留在分支详情中。

新建任务的“验证设备”读取设备资源页的采集记录。新机器先在资源页采集；过期记录会标明并
在创建时重新核验，当前项目不支持的硬件标记为“仅资源监控”。如需手动指定 backend，可展开
高级设置并启用“使用自定义连接与验收配置”。

Claude 与 FlagScale 的 API key 独立配置，使用 Windows 当前用户的 DPAPI 加密保存；普通
局域网入口提供脱敏状态与验收表格。需要协作管理时，按
[部署指南](DEPLOYMENT.md#完整权限分享链接)启用分享，再从本机「访问分享」生成链接；
持有者可创建、启动和管理任务，默认 24 小时到期，也可选择“永久有效（可撤销）”。

## 设备资源

设备资源页支持两种来源：在本机页面登录 JumpServer 后直接同步授权机器，或沿用已有 SSH
档案。无需安装 TUI。控制服务每 5 分钟在后台采集设备读数，关闭设备页也会更新。打开或切回
页面即可读取最近结果。机器列表可按需手动同步。数据过期、重启后尚未核验或驱动异常时，
不计为空闲。

JumpServer 登录用于获取资产，实时资源采集还需可用的 SSH 网关认证；详见
[设备配置](REFERENCE.md#设备资源与-jms-top)。普通 LAN 地址可直接查看适配进展、设备及
进程明细，并手动刷新资源。多个访客共用同一份缓存，手动刷新共用 30 秒冷却。任务操作仍需
本机或有效管理分享权限，JumpServer 登录与配置仅限本机。
